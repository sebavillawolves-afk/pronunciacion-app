# Pronunciación en inglés — app para iPhone

## Publicarla (una sola vez)
1. Descomprime esta carpeta en tu computador.
2. Abre Claude Code en la carpeta `pronunciacion-app`.
3. Escribe: **Lee INSTRUCCIONES_CLAUDE_CODE.md y ejecútalo.**
4. Claude Code te pedirá iniciar sesión en GitHub y el nombre del repositorio, y al final te dará un enlace.

## Instalarla en el iPhone
1. Abre el enlace en **Safari**.
2. Toca **Compartir** → **Agregar a pantalla de inicio** → **Agregar**.
3. Ábrela una vez con internet. Desde ahí funciona sin conexión.

## Notas
- El audio usa la voz del propio iPhone, la misma que lee el texto en voz alta. Para que funcione, el iPhone necesita una voz en inglés descargada: Ajustes > Accesibilidad > Contenido leído > Voces > English > elige una de Estados Unidos. La app pide sonar aunque el teléfono esté en silencio; si aun así no suena, sube el volumen con los botones laterales mientras la app está abierta.
- Las palabras que agregues en la app quedan guardadas en el iPhone. Las que agregaste en el enlace de Claude no se traspasan.
- Para actualizarla, pídele los cambios a Claude Code en esta misma carpeta. La app se actualiza sola la próxima vez que la abras con internet.
